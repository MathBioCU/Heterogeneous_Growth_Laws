This repository contains the code used to generate the figures in the paper:

> **From Individual Trajectories to Population Densities: Weak-Form Inference of Heterogeneous Growth Laws**  
> R Lyons, V Dukic, DM Bortz
> [arXiv:2609.31955](https://arxiv.org/abs/2609.31955)
---

## Data and Code References
This code uses a frozen version of the object oriented WSINDy and WENDy codebase. For updated versions of the code, see the repository:
https://www.github.com/dm973/wsindy_obj_base

The data used examples are from the following works:

E. coli data: 
P. Kar, S. Tiruvadi-Krishnan, J. Männik, J. Männik, and A. Amir (2021)
**Distinguishing different modes of growth using single-cell data.**
eLife 10, pp. e72565.
repo: Harvard DataverseDOI: [doi.org/10.7910/DVN/BNQUDW](https://doi.org/10.7910/DVN/BNQUDW)

HeLa Data:
C. Cadart, L. Venkova, M. Piel, and M. Cosentino Lagomarsino (2022)
**Volume growth in animal cells is cell cycle dependent and shows additive fluctuations.**
eLife 11, pp. e70816.
repo: [Dryad, data setDOI: doi.org/10.6078/D12M6C](https://doi.org/10.6078/D12M6C)

Loblolly Data:
Available in the R datasets package, see e.g. [stat.ethz.ch/R-manual/R-devel/library/datasets/html/00Index.html](https://stat.ethz.ch/R-manual/R-devel/library/datasets/html/00Index.html)
With referenced source:
⁠Kung FH (1986)
**Fitting Logistic Growth Curve with Predetermined Carrying Capacity.**
In Proceedings of the Statistical Computing Section, 340–343. American Statistical Association.
